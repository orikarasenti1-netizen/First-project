# חוזרים: כרטיסייה דיגיטלית שמחזירה לקוחות

כרטיסייה דיגיטלית לכל עסק קטן: בית קפה, מספרה, פיצרייה, מכון יופי. הלקוח סורק QR, כותב שם ומקבל כרטיסייה בטלפון, בלי אפליקציה. בעל העסק מחתים לפי קוד בן 4 ספרות, רואה מי הפסיק להגיע, ושולח לו הודעת וואטסאפ מוכנה בלחיצה.

הכול נמצא בתיקייה `chozrim/` ולא מחובר לשום דבר אחר באתר. Folio, Grain, Proposal ודף הבית לא שונו.

| קובץ | מה זה |
|---|---|
| `index.html` | דף נחיתה לבעלי עסקים |
| `app.html` | האפליקציה של בעל העסק: קופה, לקוחות, פוסטר, הגדרות |
| `c.html` | הכרטיסייה של הלקוח (הצטרפות ותצוגה חיה) |
| `privacy.html` | הודעת פרטיות ללקוחות |
| `js/config.js` | **הקובץ היחיד שצריך לערוך:** חיבור ל-Firebase, מחיר ופרטי תשלום |
| `firebase/firestore.rules` | חוקי האבטחה של מסד הנתונים (כולל אכיפת תשלום) |
| `tests/` | 7 קבוצות בדיקות אבטחה ו-30 בדיקות מסע מלא בדפדפן |
| `business/` | תוכנית, מספרים, תסריטי מכירה, משפטי |

## עלייה לאוויר (כ-15 דקות, פעם אחת, ₪0)

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) עם חשבון Google, יוצרים פרויקט חדש בשם `chozrim` ומדלגים על Analytics. התוכנית החינמית (Spark) לא דורשת כרטיס אשראי.
2. **Build ← Firestore Database ← Create database.** בוחרים מיקום `me-west1` (תל אביב) ו-Production mode.
3. **Firestore ← Rules:** מוחקים את מה שיש, מדביקים את כל התוכן של `chozrim/firebase/firestore.rules`, ולוחצים **Publish**.
4. **Build ← Authentication ← Get started:** מפעילים **Email/Password** ו-**Google**.
5. **Authentication ← Settings ← Authorized domains ← Add domain:** מוסיפים `orikarasenti1-netizen.github.io`.
6. **Project settings (גלגל שיניים) ← Your apps ← אייקון `</>` (Web):** רושמים אפליקציה, ומעתיקים ל-`chozrim/js/config.js` את `apiKey`,‏ `authDomain`,‏ `projectId`,‏ `appId`. הערכים האלה ציבוריים מטבעם, והאבטחה נעשית בחוקים. ממלאים שם גם את `operator.whatsapp` (מספר הוואטסאפ העסקי שלך).
7. ממזגים את ה-PR ל-`main`. האתר עולה אוטומטית לכתובת:
   **`https://orikarasenti1-netizen.github.io/First-project/chozrim/`**
8. בדיקה: נכנסים ל-`app.html`, יוצרים כרטיסיית ניסיון, מצטרפים אליה מהטלפון, ומחתימים.

אם תשלח לי את הערכים משלב 6, אני אכניס אותם לקוד ואדחוף.

## איך מסמנים שעסק שילם

Firebase console ← Firestore ← `businesses` ← המסמך של העסק (המזהה מופיע בהודעה שהעסק שולח לך מכפתור "המשך מנוי") ← **Add field**:
- שם: `paidUntil`
- סוג: `timestamp`
- ערך: התאריך שעד אליו שילמו (חודש או שנה קדימה)

בלי זה, 30 יום אחרי ההרשמה (ועוד 7 ימי חסד) ההחתמה נעצרת אוטומטית. הלקוחות ממשיכים לראות את הכרטיסיות, ושום דבר לא נמחק.

## שגרה יומית (עד 30 דקות)

1. **10 דק':** עסק חדש אחד. פגישה פנים מול פנים או הודעה לחבר (ראו `business/SALES_PLAYBOOK.md`).
2. **10 דק':** מעקב אחרי עסקים בניסיון. כמה לקוחות הצטרפו? אם פחות מ-10 בשבוע, להזכיר לבעל העסק להציע לכל לקוח בקופה.
3. **5 דק':** לענות להודעות תשלום ולסמן `paidUntil`.
4. **5 דק':** לעדכן את המספרים ב-`business/PLAN.md`.

## מה רץ לבד ומה דורש אותך

| אוטומטי | דורש אותך |
|---|---|
| הצטרפות לקוחות, החתמה, עדכון חי בטלפון | פגישת מכירה והקמה (כ-20 דקות לעסק) |
| זיהוי לקוחות שלא חזרו או שקרובים להטבה, וניסוח הודעה | סימון תשלום (`paidUntil`) |
| עצירת החתמה כשלא שולם, וחזרה כשמסמנים | שליחת ההודעות (בעל העסק לוחץ שליחה בוואטסאפ שלו) |
| בדיקות אבטחה ובדיקות מלאות בכל שינוי (GitHub Actions) | |

## בדיקות

```bash
cd chozrim && npm install && npx playwright install chromium
npm run test:rules   # 7 קבוצות בדיקות אבטחה על אמולטור Firestore
npm run test:e2e     # 30 בדיקות מסע מלא: בעלים, לקוח בטלפון, החתמה חיה, הטבה, וואטסאפ, תשלום
```
